# VERIFICATION_GUIDE：考证质量标准与引文门禁

- 状态：生效（2026-11-01，评审第十二轮批准 scope）
- 定位：**方法与门禁的单一来源**。本文不含：调研结论（见 `docs/research/`）、
  未回溯的考辨条目、与 ADR 重复的规则条文（引用节号，不复制——防漂移源）。
- 通用原则：**条目的级别由"内容可核性"决定，与社区热度无关**——0★ 仓库的考辨
  可以是 C 级线索，500★ 无书证项目同样不得引用。

## 一、引文分级：判定条件与允许用途

| 级别 | 判定条件 | 允许用途 | 禁止用途 |
|---|---|---|---|
| **A** | 影印/官方数字版**逐字核到** + `citation.url_or_path` 填写 | 录入 `quote`（quote_kind=原文）；作"已考证"的依据 | — |
| **A-** | 在线权威本（识典/维基文库）逐字核到，**未开影印页** | 录入 quote，notes 标注"影印对照待复核" | 作为已考证的唯一依据 |
| **B** | 二手转述/检索摘要 | 登记 notes 线索 | 进 `quote` 字段；出现在规则解释的肯定陈述中 |
| **C** | 未回溯一手来源的线索（含 research/ 下的考辨条目） | **触发"引用前必须核查"** | **任何判定依据；排除某部书的理由** |

C 级规则与 ADR-0014"有争议规则不参与否决"同逻辑：**未核实的排雷信息只产生警示，不产生排除力。**

## 二、书目权威 vs 文本权威（两类源，别混用）

| 类型 | 解决的问题 | 源 | 局限 |
|---|---|---|---|
| **书目权威** | 这本书是什么、谁写、何时、是否托名 | 《四库全书总目》（ctext/识典可查）、正史艺文志、出土文献著录 | 解决不了"字是什么" |
| **文本权威** | 这个字/句在版本里是什么 | 影印页（书格、维基共享资源四库影像）、**多版本对校** | 不同版本卷次划分有差 |

**托名判定的可操作步骤**（同期官修目录著录核查）：查该书成书年代**之前与同期**的官修目录
（《永乐大典》类书、《四库全书总目》等）是否著录——例：《滴天髓》在明《永乐大典》、
《三命通会》、清《四库》均未提及 → 托名信号（成书年份下移至清中后期）。

**可采性优先于真伪**（四库馆臣对术数类的总体态度："所言可采，即录存以备一家"）：
**伪托/存疑不排除引用**——托名文献若为某时代择日实践的事实来源，仍是有效证据。
**操作指引**：若书伪而术可核（如《滴天髓》托名但体系可追溯至明代以前），则
`citation.book_authenticity` 标 `pseudepigraphic`（或 `disputed`，视确证程度），
`quote` 引用**可核版本**的原文并在 notes 注明托名状态——不得声称"古法/原著"。

## 三、citation 字段规范（逐项填写规则）

| 字段 | 填写规则 | 示例 |
|---|---|---|
| `source` | 书名全称带书名号 | 《协纪辨方书》 |
| `edition` | 版本全称（未定填 null） | 四库全书本 / 郑同点校本 |
| `juan` | 卷次（版次间有差的必须双记） | 三十四（四库本；通行本归三十三） |
| `pian` | **篇次优先于卷次**（版次稳定） | 利用一·制煞要法 |
| `entry` | 条目名（含转引来源） | 制煞要法（引《选择宗镜》） |
| `quote` | **逐字原文**，异体照抄；省略号=原文有间隔 | 太歲可坐不可向…… |
| `quote_kind` | 原文/白话转述/通行口径 | 原文 |
| `url_or_path` | 可回访的在线链接或影印件路径 | https://…（识典） |
| `verified_by` | **人类**考证人姓名（Agent 禁填） | 待定 |
| `verified_at` | 签名日期 | 2026-11-01 |
| `confidence` | 低/中/高（对应引文分级） | 中 |
| `book_authenticity` | authentic/disputed/pseudepigraphic/缺省=待核 | authentic |

## 三·二、影印对校操作流程（五步，考证人按此执行，不得各自发挥）

1. **定底本**：确定采用版本（四库本/点校本）与其影印源（书格/维基共享/图书馆扫描件），
   `edition` 记录；多版本并存时 `juan` 双记。
2. **定位**：按 `pian`（篇次）定位卷内位置——目录以篇次为准（卷次版次间有差，ADR-0013）。
3. **逐字抄录**：目标句繁体照抄（异体字照抄，不"规范化"），句间省略用"……"并注明
   "原文中或有间隔文字"。
4. **比对**：与在录 quote 逐字 diff——异体/形近（戊己/戊巳类）**记录差异，判定采用字，
   采用理由写进 notes**（"断句/定字以影印为准"）。
5. **签名存档**：`verified_by` + `verified_at` + `url_or_path`（影印页可回访）。
   **何时必须升 A**：quote 进入任何 `已考证` 规则前；两个在线本文字有出入时；定字争议未决时。

## 三·三、状态跃迁（触发证据 / 权限 / 可逆性）

| 跃迁 | 触发证据 | 谁有权 | 可逆性 |
|---|---|---|---|
| 待考证 → 已考证 | A 级 quote + `verified_by` 人类签名 + commit trailer `Verified-B y:` | 考证人（人类） | 可逆：回退须 notes 注明原因（如影印复核发现异文） |
| 待考证/已考证 → 有争议 | 原文与建模方向冲突（如 ADR-0013 三煞占向） | 评审或考证人 | 可逆：Q-0xx 裁定后按裁定迁移 |
| 伪托/版本判定变更 | `book_authenticity` 变更 | 考证人 | **联动重审**：引用该书目的全部 `已考证` 规则当轮降回 `待考证` 重审（lint 列清单），签名不自动沿用 |

## 三·四、伪托/待核书目处理流程

- 引用"待核"书目的规则：**status 不自动降级**，但 lint 对 `book_authenticity` 缺省的书目
  所在规则输出提示（接线随 C15 后续）；解释/notes 不得声称"古法/原著"。
- `book_authenticity` 被判定为 `pseudepigraphic`/`disputed` 时：**当轮重审**引用该书目的
  已考证规则（流程见三·三末行）——重审结果可以是"维持已考证"（伪托不影响事实效力，
  见二"可采性优先于真伪"），但必须显式复核而非默认沿用。

## 三·五、C21 静态层的命名空间与占位豁免（跨模块依赖注记）

静态扫描覆盖 `facts./time./course.` 三命名空间；**跨模块依赖**（如 course.day.zhi 由
四柱派生链产出）为运行时隐式产出，静态扫描不追踪派生链——跨模块正确性需人工审查。
`op: exists` + 输入 fact 的**就绪探测占位**（如 ZWX-XIANGSHOU-001"相主口径待裁定"）不是
吉凶死规则，静态层豁免——豁免为**三重条件**（exists + 待裁定标记 + 裁定队列登记 Q-013），
缺一照报；Q-013 裁定完成（QUESTIONS 标"已裁定"）后豁免失效，占位规则必须处置。
**测试锚点**：`test_c21_static_candidate_specificity`（含"删 Q-013 登记必须重新报警"反证）、
`test_zwx_placeholder_not_evaluated`（占位不参与评估实证）、`test_lint_check_id_groups_exact_sets`。
**零命中可达性归因**：docs/research/reachability-2026-11.md（13 条均为门控未开/起例待核）。

## 三·六、C20 分歧不仲裁声明

`docs/research/calendar-diff-register-2026-11.md` 的分歧记录**不是错误清单**——是各
oracle 算法差异的登记，供考证人复核；**禁止多数票仲裁**（oracle 独立性无证）；
修复 zeri 的唯一路径 = 分歧 → QUESTION → 对照 GB/T 33661-2017 / 紫金山《中国天文年历》
人工裁定。该标准只锚定**历法算术**，"对算一致"≠"择日体系正确"。

- 现有字段：`kind / source / edition / juan / pian / entry / quote / quote_kind /
  url_or_path / verified_by / verified_at / confidence`（loader 校验见 ADR-0014 引用节）。
- **新增 `book_authenticity`**（待核为缺省）：`authentic`（官修/原著，
  如《协纪辨方书》清乾隆敕撰、四库著录）｜ `disputed`（托名/成书存疑）｜
  `pseudepigraphic`（确证托名）｜ 缺省 = 待核。
- 现有规则库书目首版登记：协纪辨方书=authentic（官修）；象吉通书、鳌头通书=待核
  （清代民间实存刻本，非伪托问题但编者/版本待核）；杨公忌日=待核
  （托名杨筠松传统，口诀成因待核——阻塞于一手来源）。
- **文本权威操作**：识典在线本核到（A-）→ 影印页对照（A）→ 多版本对校定字
  （案例：戊己/戊巳，见 ADR-0013 第二节）。**何时必须升 A**：quote 进入任何
  `已考证` 规则前；两个在线本文字有出入时；定字争议（异体/形近）未决时。

## 四、状态跃迁提权

`待考证 → 已考证` 须 `verified_by` 非空（loader 硬校验 + lint 纵深 +
`Verified-B y:` commit trailer）——条文见 ADR-0014「状态跃迁提权」节与 loader，
本文不复述。Agent 不得代签（AGENTS.md 硬禁止第 1 条）。
**签名黑名单为启发式辅助而非完备保证**（评审第十三轮）：lint 对已知非人类署名
（pytest/agent/AI/llm/bot 等，**全等匹配**大小写折叠——"Aijing" 类人名不受影响）
报 error；完备防线 = status 变更权限约束（CODEOWNERS/分支保护，工程侧待接）。
**测试锚点**：`test_agent_signature_blacklist`。

## 五、权威源清单

**书目权威**：《四库全书总目》（识典古籍/ctext 可检索）、正史艺文志（《汉书·艺文志》以降）、
出土文献著录。
**文本权威**：识典古籍（在线标点本，A- 级）、维基文库四库本（A- 级，可交叉）、
书格（影印下载）、中国哲学书电子化计划 ctext（**术数类收录非全备**）、
**中华古籍资源库**（国家图书馆·国家古籍保护中心，read.nlc.cn，免费注册读影印——
2026-11-01 核实名称；此前"国家古籍数字化资源总平台"为误称，已更正）。
规范依据（历算类）：GB/T 33661-2017《农历的编算和颁行》（2017-05-12 发布，紫金山天文台起草）。

## 六、直引率信号（定义，接线随 C15 后续）

`直引率 = 已签名原文 quote 的断言级规则数 / 断言级规则总数`——lint/报告持续亮牌；
当前基线为 0（42 条断言级全部待考证/有争议），P0 考证的过程就是直引率爬升的过程。
