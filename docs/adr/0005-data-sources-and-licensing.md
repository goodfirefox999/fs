# ADR-0005：数据来源与版权边界

- 状态：已采纳
- 日期：2026-11-01
- 决策者：实现者（Agent），待人类复核

## 背景

择日规则几乎全部来自古籍与现代通书。若不加约束，极易出现两类问题：
（a）Agent 编造出处；（b）把有版权的现代通书内容入库分发。

## 决策

1. **规则库只登记公版古籍书名**（《协纪辨方书》《象吉通书》《鳌头通书》等），
   `citation.quote` 一律为 `null`，直到人类考证者填入真实原文与卷次。
2. **`status: 已考证` 是硬门槛**：必须有 `quote` + `verified_by`，否则加载期即报错
   （`loader.py` 校验）。这条规则使"编造出处"在技术上无法通过 CI。
3. **案例原文快照**（`cases/raw_snapshots/`）为内部参考，不入公开分发；
   `source.license_note` 字段强制说明版权状态。
4. **不内置任何现代出版物全文或数据库**；论坛采集数据（`data/cases/forum_scrape/`）
   仅作案例来源线索，未结构化入库。
5. **不使用在线黄历 API** 作为计算源（`tools/no_network_scan.py` 强制）。

## 理由

- "无原文即不可已考证"这条技术约束，比任何文档告诫都更能阻止 Agent 编造。
- 公版古籍书名属于事实性引用，不构成侵权；而摘录现代通书正文则有版权风险。
- 案例快照是"防删帖"措施（论坛已宕机，见 `data/cases/forum_scrape/README.md`），
  属于合理使用范围内的存档，但不宜公开分发。

## 后果

- ✅ 当前 42 条规则全部 `待考证`，系统默认不产生正式结论 —— 这是**正确**的状态，不是缺陷。
- ⚠️ 规则库的实用价值取决于人类考证进度（M4 是瓶颈，见 DEVELOPMENT.md 第 12 节）。
- ⚠️ 若将来引入授权现代通书，需在 `citation.edition` 与 `source.license_note` 中记录授权信息。
