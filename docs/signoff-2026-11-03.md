## 四、签名的三条硬前提

1. **原文**：影印逐字，卷次 + 叶次 + URL 齐备（`quote_kind: 原文`，不是转述）；
2. **起例**：代码与原文起例逐字一致，不是「差不多」；
3. **适用范围**：事项范围与卷十/卷十一宜忌条一致，不泛化。

三者缺一，保持 `待考证`；`已考证` 需人类签名 + `Verified-By:` trailer。

## 五、签名前必读：安葬必需集 10 条的 A/B/C 分级

> 六合签完（1/1）后，最可能被问的是「剩下还要签多少条才能可发布」。
> 答案是：**不是再签 9 条。** 先分级，再算账。

安葬必需集 = 8 条无输入依赖 + 2 条命主相关（未提供命主时后两条不进集）。
按「原文证据到了哪一步」重排（2026-11-04，规则文件 + 四库本实查）：

| 级别 | 定义 | 规则 | 条数 |
|---|---|---|---|
| A | 有原文，可直接签 | `PUB-SUIPO-001` 岁破、`PUB-SANSHA-001` 三煞年、`PUB-SANSHA-002` 三煞月、`PUB-SILI-001` 四离、`PUB-SIJUE-001` 四绝 | 5 |
| B | 有出处线索，未定位影印 | `PUB-WUHUANG-001` 五黄 | 1 |
| C | 连原典条目都未定位 | `PUB-YUEPO-001` 月破、`PUB-CHONGSHAN-001` 日冲山、`PUB-CHONGMING-001` 日冲命、`PUB-MING-SANSHA-001` 年命三煞 | 4 |

**四离四绝是 A 级**：卷十·用事宜忌明写「止不忌祭祀解除沐浴……餘事皆忌」，
按语「四离四绝……故诸事不宜」——安葬在「餘事皆忌」内，文本支持安葬硬否决
（卷十影印叶次待补；详见红线二与 Q-027）。此前把它列为「原文不支持安葬」是
**误读**：卷六义例只引李鼎祚「忌出行征伐」，卷十才是铺注规则；卷十一安葬忌列
不重复列名，不等于不禁。

**A 级也不是拿来就签**：岁破虽有 A 级引文（「向太歲則坐于歲破矣…」，ADR-0013 P5），
但未录入规则、无影印叶次；三煞两条要先定 Q-002（方位组/具体煞名）与
Q-020（三山/整方）；四离四绝要先补卷十影印叶次。**B 级五黄**按 ADR-0013 D3 判据，
若 B/C 则默认降慎用 + 移出必需集，不用签名。

**签名级引文（卷次 + 叶次 + URL + 人类签名）仍是 0 / 10**——A 级 5 条也只是
「有引文/有线索」，没有一条达到签名三条硬前提。必需集不是做不到，是还没做。

**参照**：不在必需集的天德 / 天赦 / 月德 / 月德合四条，以及六合，都已有
「卷次 + 叶次 + URL」的完整影印引文。

### 最少签几条：5～8 条（文本忠实路径）

`publishable` 要求必需集每条都「状态可签 + 可判定」。按处置不同算账（安葬、不提供命主）：

| 情景 | 十二地支山需签 | 乾山 + Q-026「四维不忌」需签 |
|---|---|---|
| 全部保留 | **8** | **7**（日冲山不适用，少 1 条） |
| 五黄降级移出（ADR-0013 D3） | **7** | **6** |
| 月破/日冲山也找不到原文、一并移出 | **5** | **5** |

**「最少 3 条」的说法已撤回**：它建立在「四离四绝原文不支持安葬」的误读上。
卷十明写「餘事皆忌」，两条按文本应留在必需集。只有在师傅**显式裁定 Q-027 方案 A**
（收窄到出行，且给出师承依据、承认偏离原文）时，才可在上表基础上再减 2 条
（6/5 → 5/4 → 3/3）；那是登记在案的偏离，不是默认路径。

**三个裁定**：Q-027 维持安葬（建议 C）还是显式收窄（A）、ADR-0013 D3 五黄是否降级、
C 级 core 2 条（月破、日冲山）能否找到出处。

**山型会改变答案**：十二地支山必须解决日冲山（C 级）——签或移出；
乾山 + Q-026 裁定「四维不忌」后，日冲山标「不适用」、不阻塞，**少签 1 条**。
所以验收案例选乾山还是地支山，会直接改变「还差几条」的答案。

**A 级 5 条的前提**：三煞两条先定 Q-002 / Q-020 口径；四离四绝先补卷十影印叶次。
口径/叶次未定则不可签——那是前置阻塞，不是缺原文，签不了不等于要移出。

命主相关的两条（日冲命、年命三煞）只在提供命主时进必需集；
验收案例不提供命主即可不计入。

**一句话结论**：不是签 9 条；**最少 5 条，现实 6～7 条，全部保留 8 条**。
只有师傅明确选择偏离卷十原文，才可能降到 3 条。

### 红线一：`PUB-CHONGSHAN-001` 在四维山上「签了也 True 不了」

乾/坤/艮/巽 四维山没有地支，引擎给 `site.shan_jia_zhi = None`。真实案例（乾山 315°）
该条判的是「输入不足」，remedy 写着「补输入即可判定：site.shan_jia_zhi」——
但四维山正针没有地支可补。**必须先由人裁定四维山如何取山家**（Q-026，与 Q-021 兼向口径相关）。

**工程侧已就绪（工作区未提交）**：引擎新增参与状态「不适用」，与「输入不足」分开；
规则可声明 `not_applicable_when`，命中后不阻塞 `publishable`。口径 `q026_sishan_chong`
默认 `undecided`（仍是「输入不足」），裁定「四维不忌」后切 `not_taboo` 即生效。
`tests/unit/test_not_applicable.py` 已覆盖四种情形。

**验收建议**：验收「必需集签完 → 可发布 = 是」要用**十二地支山、且未触发否决**的案例（如子山）；
乾山案例只用来验收「六合 1/1」。若 Q-026 裁定「四维不忌」，乾山也可以验收 publishable，
但那是另一条路径，不能与地支山案例混用。

### 红线二：四离 / 四绝是「诸事不宜」，安葬在「餘事皆忌」内（2026-11-04 修订）

两条规则的 `task_kinds` 为空；空值语义是**适用全部事项**——包括安葬，且是硬否决。
**这与卷十一致，不是超范围。** 此前「原文不支持安葬」的结论是误读，已撤回。

- **卷十·用事宜忌**（四库全书本，维基文库转录；影印叶次待补）铺注规则：
  「上朔　四离　四绝　晦日 / 止不忌祭祀解除沐浴整容剃头整手足甲补垣塞穴扫舍宇
  修饰垣墙平治道涂破屋坏垣伐木**餘事皆忌**」；按语：「四离四绝为二气五行分判之日……
  **故诸事不宜**」。
- **卷六·义例四**（`06056507.cn` n148–n149）只引李鼎祚「此日忌出行征伐」
  「此日忌出軍遠行」，曹震圭只作五行解释——这是**义例溯源**，不是铺注用的规则。
  把这一句当成完整适用范围，才会得出「只忌出行」。
- **卷十一·用事宜忌**的安葬（`06056511.cn` n51）、破土（n50）、行幸遣使·出行同（n22）
  忌列未列四离四绝，**不能反证安葬不禁**：卷十是「诸事不宜」的通则层，
  卷十一是分事项的神煞忌列层；通则已禁的日子不必在每个事项里重复列名。
  另注意安葬忌列里的「四忌」「四窮」是另外的神煞，不可与四离四绝混淆。

**结论**：文本支持四离四绝作为安葬硬否决。**Q-027 建议 C（维持安葬）**；
若师傅要收窄到出行，必须给出师承依据并显式承认偏离卷十，不能再说「原文不支持」。
原 patch `docs/patches/0001-sili-sijue-scope.patch` 已撤回为
`.patch.withdrawn`，**不得应用**。签名前仍需补卷十影印叶次 + 逐字 quote。

## 六、签名后的验收（同一真实案例）

- 案例：`2027-07-14T09:00`，未月甲午日，坐山乾（315°），安葬/破土，主命庚戌。

| 指标 | 签名前 | 签名后 |
|---|---|---|
| 共识比 | `0/0` | **`1/1`** |
| 投票派 | `[]` | `['sanhe']` |
| 全局已考证规则 | 0 / 86 | 1 / 86 |
| 安葬必需集已签 | 0 / 10 | **0 / 10** |
| `publishable` | `False` | **仍为 `False`** |

**必须向师傅说明**：`1/1` 只表示「第一次有门派投票」，**不等于可发布**。
签名后报告仍会显示「可发布 = 否」，原因是安葬必需集 10 条（8 条 core + 2 条命主相关）
全部仍是 `待考证`，且六合不在必需集内——**不是签名没生效**。
这是 ADR-0012 的安全底线语义：`publishable` 只表示必需风险集已全部可判定，不表示日期可用。

**再往前一步**：签名生效后，这个**乾山**案例仍会显示「可发布 = 否」——不是因为六合没生效，
而是安葬必需集仍是待考证。其中 `PUB-CHONGSHAN-001` 在四维山上默认判「输入不足」
（Q-026 未裁）；若 Q-026 裁定「四维不忌」，本条转「不适用」、不再阻塞；
Q-027 维持安葬后，四离四绝仍需签名才能不阻塞（不是靠 patch 移出）。
两步都完成后，乾山案例的阻塞清单只剩 A/B/C 级的未签规则，届时可作
「q026_sishan_chong=not_taboo」路径的 publishable 验收案例。
十二地支山路径不同：日冲山必须签或移出，验收案例不能混用。
